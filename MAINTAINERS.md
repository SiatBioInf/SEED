# Maintainers

The manuscript's final two corresponding authors are the designated long-term maintainers of SEED:

| Maintainer | Contact | Primary responsibility |
| --- | --- | --- |
| Hao Yu | hao.yu@siat.ac.cn | Repository releases, data and analysis workflow coordination |
| Xin Hong | hongx@sustech.edu.cn | Scientific review, issue triage and continuity of maintenance |

Both maintainers oversee pull requests, issue triage and release corrections. The project team reports that both can manage the code-hosting site; their GitHub access levels should be checked in the repository's collaborator settings when the release is published.

Please report reproducible problems through GitHub Issues. For changes to analysis code, submit a pull request and request review from at least one maintainer. Changes that alter the released state definitions, cell-evidence rules or archived outputs should be reviewed by both maintainers before release.
